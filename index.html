API keys

Keys are stored only in this browser (localStorage) and sent only to the provider they belong to. All three have free tiers.

  • No key needed: "Daily NSE data" reads what a scheduled GitHub Action downloads every weekday evening from NSE's published reports: every NSE index, plus the stocks in data/watchlist.json (edit it on GitHub to change the list).
  • Twelve Data (twelvedata.com, free): asked for NSE/BSE directly; its free plan may not include Indian exchanges, and the app shows Twelve Data's own message if not.
  • Alpha Vantage (alphavantage.co, free): BSE listings, last 100 daily bars only.
  • CSV: download from nseindia.com (Get Quote → Historical Data), niftyindices.com (index history), bseindia.com, or your broker (e.g. Zerodha Console), then choose "Upload CSV".
  • No free feed carries Indian company news; the Desk points to NSE announcements instead.
